# SEE64YOU v0.1.0-alpha.1 — installation and safety guide

**Status: released early alpha, 20 October 2026.** This is the **existing** software, not the planned 8TML-compatible edition. It reads/writes SEE64YOU `.s64` source and works with the supplied PHP website. It **cannot** yet publish `.8tml` to T8WN or open sites in the VVV browser. The [8TML direction](../8TML-ROADMAP.md) is future work, independent of T8WN availability.

**Experimental. Back up your C64U SD files, configuration and website before testing. Use a disposable directory/site and non-sensitive documents. Some manual-keyboard, cold-power and interruption acceptance is still incomplete; this is not a dependable public beta.**

## Get the correct files

From the [GitHub v0.1.0-alpha.1 prerelease](https://github.com/dannykeat-projects/SEE64YOU/releases/tag/v0.1.0-alpha.1):

- `SEE64YOU-v0.1.0-alpha.1-c64u.zip`: all **eleven matching installed C64U files**, including four user-facing programs and private assets. **Do not install a single PRG alone.**
- `SEE64YOU-v0.1.0-alpha.1-php-site.zip`: separate self-hosted legacy website for publishing; requires PHP 8.1+ and HTTPS **for initial pairing**. No database is required.
- `SHA256SUMS`: compare hashes of downloaded ZIPs. Source and tested package details are recorded in the tag and the release notes.

Do not mix files from different releases.

## C64 Ultimate prerequisites

- Commodore 64 Ultimate firmware with UCI and Ultimate-DOS; tested baseline **firmware 1.1.0** and Network Target `$03`.
- **Ultimate menu → F2 Settings → C64 and Cartridge Settings**: Command Interface **Enabled**; RAM Expansion Unit **Enabled**; REU Size **16 MB** (16 MiB), not a smaller setting.
- Writable SD card. Copy the entire unzipped `SEE64YOU` client folder to **`/sd/SEE64YOU/`** so all eleven matching files sit together.
- Leave your normal turbo setting alone. Network access is needed for Publisher and Browser, not offline editing.

This program uses Ultimate-specific features. An original stock C64 or VICE with only a generic REU is not an equivalent supported environment.

## Launch the correct program

| Run on C64U | Role |
| --- | --- |
| **`SEE64YOU.PRG`** | **Editor — launch this to write, open and save** `.s64` files; uses internal overlay files |
| `S64PUB.PRG` | Standalone Publisher — load saved `.s64`, publish/update, or download remote source to a **new** file |
| `S64CFG.PRG` | Settings — configure site and dedicated publishing key |
| `S64WEB.PRG` | Optional read-only SEE64YOU-site reader; not an HTML browser and not a VVV/8TML reader |

**Do not launch `S64EDIT.PRG` directly.** It is a private/internal Editor component. All four user entry programs are independently launched and return to BASIC; no launcher-to-Publisher live session is required.

## Offline editor check (no website required)

1. Launch `SEE64YOU.PRG` from the complete installed folder. If a prerequisite screen appears after changing Ultimate settings, press **R** to recheck.
2. Start a new document (`Ctrl+N`), type a short **non-sensitive** test, then save (`Ctrl+S`) as `FIRST`. A new basename receives `.s64` automatically and is saved under `/sd/SEE64YOU/` by default.
3. Exit with RUN/STOP; save or cancel if warned about unsaved edits. Reopen using the Editor to inspect the document. Keep a separate backup before further experiments.

Keyboard behaviour, reopen/edit/update and physical interruption cases are not all finally certified; report observed differences and preserve the original files.

## Optional: create a legacy SEE64YOU website and publish

1. Upload the **contents** of the separately supplied `see64you-site` folder to a new PHP 8.1+ website directory, including hidden files and included setup marker. Do **not** overwrite an existing live site. Configure write permissions and protect `data/` from direct web access (included `.htaccess` works on compatible Apache; other servers require equivalent rules).
2. Open `start.php` with a modern browser and follow the first-install guide; use `setup.php` as directed. Do not re-enable setup on an existing configured installation.
3. Open **`pair.php` over HTTPS** to obtain the dedicated **64-hex-digit** publisher key. Keep it private. Import using `/sd/SEE64YOU/SEE64KEY.TXT` or enter it in `S64CFG.PRG`; remove the temporary import file afterwards.
4. In `S64CFG.PRG` configure the legacy site's exact **`http://` folder URL**, *without* `api.php`, confirm the explicit plaintext warning, and save until **SETTINGS SAVED AND VERIFIED**. A host that forces HTTP → HTTPS redirect is **not compatible with this direct firmware-1.1 transport**. Do not disable host security just to make a test work; manual/offline editing remains available.
5. Launch `SEE64YOU.PRG`, save `FIRST.S64`, exit. Launch `S64PUB.PRG` separately; load the file, connect, select page/post and draft/published state, then publish. Verify the result in a modern browser. For remote edits, Publisher downloads to a **new filename** so an existing local file is not silently overwritten.
6. `S64WEB.PRG` can open **plain HTTP** SEE64YOU-compatible public text/link pages; it does **not** fetch arbitrary HTML, HTTPS, 8TML or VVV content.

**Security:** C64U direct publishing uses dedicated challenge/HMAC authentication and replay/body integrity protections over **unencrypted HTTP**. It does *not* encrypt document contents or hide URLs/traffic from observers. Do not publish private data through this path. Never put your usual website password or a reusable bearer token in C64U plaintext HTTP requests. HTTPS is required for initial browser-based pairing and is **never silently downgraded**.

## Known limits and confidence

Binaries and published ZIPs were created for the v0.1.0-alpha.1 tag; historical reports include local package/VICE/PHP checks and bounded C64U Settings, filename, direct-publish/download and restoration tests. This document update does **not** rerun them. Full first-time physical-keyboard/cold-start acceptance, USB-keyboard and uncontrolled power/SD interruption handling remain unfinished or deferred. Save backups, use disposable content and report exact reproduction steps.
