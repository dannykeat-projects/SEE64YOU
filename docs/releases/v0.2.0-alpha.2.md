# SEE64YOU v0.2.0-alpha.2 — installation and use

This is an **experimental 8TML Editor preview**, not a completed browser/publishing ecosystem. Back up existing files and use disposable content.

## Install

Download the SD or USB0 client package and verify `SHA256SUMS`. The SD package installs under `/sd/SEE64YOU/`; the USB0 package works only when the actual mount is `/Usb0/`. Other mount names require a complete `STORAGE_ROOT` rebuild. Copy all **eleven matching files**, preserving existing documents/configuration/recovery data. Do not execute a program that fails exact upload/readback verification.

On the Ultimate, enable **Command Interface**, **RAM Expansion Unit** and **REU Size 16 MB** under **Memory & ROMs** (or **C64 and Cartridge Settings**). Launch `SEE64YOU.PRG`, not internal `S64EDIT.PRG`.

## Edit

Create a new document or open an existing `.8tml` file. New source begins with an editable `8tml: 1`/title header. Ctrl+S saves (a basename `FIRST` becomes `FIRST.8tml`); Ctrl+Shift+S saves under a new name; Ctrl+O opens; F8 shows Help. Commodore+F3/F5/F7 offer native Open/Save/Save As alternatives. The full source remains intact including unknown metadata and markup. The complete source limit is 61,440 bytes, stored as ASCII/LF.

**There is no autosave.** Save explicitly. A recovery snapshot, if already present, can be offered for reopening; failed recovery leaves it intact. RUN/STOP requires confirmation before exit and offers Save/Discard/Cancel for dirty source.

## Optional publishing

`S64CFG.PRG` configures the standalone PHP 8.1+ site and a dedicated key paired over HTTPS. `S64PUB.PRG` loads `.8tml`, publishes/updates and downloads into a new filename; its real-hardware end-to-end acceptance is pending. Direct `http://` publishing is **unencrypted**, although challenge/HMAC authenticates requests; explicit user consent is required. Modern-site HTML rendering covers only a limited safe 8TML subset. The packaged site-reader executable is not an 8TML browser; use an external compatible 8TML reader.
