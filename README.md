# SEE64YOU

A simple text editor for the Commodore 64 Ultimate which supports 8TML, with a small companion for publishing to a compatible 8TML server.

It has many functions you would expect in a modern editor, with multiple undo/redo, copy/cut/paste with shortcuts, dropdown menus, formatting shortcuts and menus, and mouse support.

## What is 8TML and why is there an editor/publisher?

8TML is a web standard for 8-bit machines which is forward-compatible. The dream is that you will be able to create, publish, and view content on the internet from any machine advanced enough to display text.

This editor was built to provide support for C64U owners who would like to jump into writing 8TML immediately.

SEE64YOU remains under active development and is heavily supported with AI tools, but basic documentation like this readme file will always be written by a human. If you manage to develop a better 8TML editor, please let me know because I will recommend and use that instead.

## Get started

See [installation and first document](docs/INSTALL.md) for prerequisites, copying the complete matching package, Editor controls and optional publishing setup. 

The latest [GitHub Releases](https://github.com/dannykeat-projects/SEE64YOU/releases) are here for download.

The Editor saves **only when you ask it to** (Ctrl+S / File → Save or Save As). It does not autosave.

**Security:** direct C64U publishing over HTTP uses a site-specific challenge/HMAC key for authentication and integrity; it **does not encrypt document content**. 

A key must be generated by the 8TML server and saved to your Commodore 64 Ultimate so they can talk to each other. Follow instructions to pair the key.

The supported client build is:

~~~sh
make -C client independent-package
~~~

The default storage root is `/sd/`. Install the whole package with the four PRGs in `SEE64YOU/` and verified `.BIN`/`.MNF` files in `SEE64YOU/SYSTEM/`. To build for an actual USB mount, rebuild the **whole** package with the corresponding `STORAGE_ROOT` (including trailing slash); there is no automatic fallback. Do not mix files between builds. Current main stores ordinary source in `SEE64YOU/docs/`; released alpha.6 uses the root. Settings and recovery stay at the root. See installation before upgrading.
